# MP3 MIDI Tool

MP3 MIDI Tool is a browser-based collection of local audio and MIDI utilities. It helps musicians and arrangers move between recorded audio, editable MIDI, rendered audio, and sheet music without uploading a selected file to the site.

Website: [mp3miditool.com](https://mp3miditool.com/)

## Available tools

- [MP3 to MIDI](https://mp3miditool.com/): Transcribe an MP3, M4A, or FLAC file into a downloadable editable `.mid` file in the browser.
- [WAV to MIDI](https://mp3miditool.com/wav-to-midi/): Transcribe WAV, MP3, M4A, or FLAC audio into a downloadable `.mid` file in the browser.
- [Audio to Sheet Music](https://mp3miditool.com/audio-to-sheet-music/): Turn supported audio or MIDI input into rendered sheet music, with MusicXML and score downloads where available.
- [MIDI to Sheet Music](https://mp3miditool.com/midi-to-sheet-music/): Read a `.mid` or `.midi` file and render its note events as sheet music in the browser.
- [MIDI to MP3](https://mp3miditool.com/midi-to-mp3/): Render a `.mid` or `.midi` file locally and download the result as MP3 or WAV.

## Local processing

The conversion tools run in the visitor's browser. Selected audio and MIDI files are processed locally and are not uploaded to the website. No account is required to use the tools.

## Repository

This repository contains the static site source, browser-side conversion code, article content, and the assets used to publish MP3 MIDI Tool.
