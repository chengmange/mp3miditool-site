Audio input guide

How to turn audio into editable MIDI

Match the converter to the source file before transcription. The tool on this homepage accepts .mp3; the WAV to MIDI tool accepts .wav and .mp3. Both create a downloadable .mid file in the browser.

Input

Start with the clearest part

Choose a passage dominated by one instrument or voice. If drums, vocals, and accompaniment overlap, isolate the part you need before asking the MIDI converter to identify notes.

Conversion

Turn the recording into note events

Run the file through the matching audio to MIDI tool and download the result. The output stores pitch, start time, and duration as editable events; it does not copy the original waveform.

Repair

Check splits, omissions, and timing

Open the .mid file in a piano roll. Merge short fragments that belong to one held note, restore a missing pitch, remove false detections, then set tempo and bar alignment before arranging.

Measured check: the same four-second phrase was converted from WAV and MP3 on the live site. Each run found all four source pitches and produced five note events: four long notes and one short split note. Each downloaded MIDI was 93 bytes.
